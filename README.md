# Bank Loan Analysis – SQL

## Project Overview

Bank loan data analysis using MySQL to validate data, integrate related tables, and generate business-focused KPIs.

## Tools

- MySQL
- SQL

## Analysis Performed

- Data validation and quality checks
- Duplicate ID checks
- Table structure validation
- Relationship validation between finance_1 and finance_2
- SQL JOIN analysis
- KPI development

## Key KPIs

1. Year-wise total loan amount
2. Grade and sub-grade wise revolving balance
3. Payment analysis by verification status
4. Loan analysis by state and last payment date
5. Home ownership and loan analysis

## SQL Files

- `01_Data_Validation.sql` – Data validation and quality checks
- `02_KPI_Analysis.sql` – Business KPI queries
- `Bank_Loan_Analysis_MySQL.sql` – Main SQL analysis script

## Key Outcome

The analysis validates the loan datasets and uses SQL joins, aggregations, grouping, filtering, and conditional logic to derive business-focused loan performance insights.
